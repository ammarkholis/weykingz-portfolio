Problem Solving

Case studies

Real issues I've debugged in production — what broke, how I found it, and what changed.

Data Production recap showed the wrong hours every day

Problem

The machine dashboard's daily summary didn't match the raw log: the day rolled over at 07:00 instead of midnight, and some state changes were never counted.

Root cause

The recap was built incrementally in memory using UTC dates, so a restart or a missed transition corrupted the totals.

Fix & result

Replaced it with a full recompute from the event log using SQL window functions, cut at local midnight, then backfilled 7 months of history (1,600+ daily rows) after taking a backup.

Web Hosting Subdomains went down after a hosting migration

Problem

After moving cPanel to a new VPS, internal web apps such as the QR document portal stopped opening — some didn't resolve, others threw PHP fatal errors.

Root cause

Three things at once: internal DNS still pointed to the old server, the app's Composer dependencies (vendor/) weren't carried over, and the new server's minimum PHP was 8.1 while the apps were built for 7.1.

Fix & result

Updated the internal DNS records, restored the missing dependencies, then checked and patched the legacy code for PHP 8.1. Both portals came back online.

Network Firewall rules that never blocked anything

Problem

Social media was supposed to be blocked at a branch site, but every app still worked.

Root cause

The rules referenced an address list that didn't exist, and FastTrack let traffic skip inspection anyway.

Fix & result

Rebuilt the policy as one re-importable script: DNS sinkhole + TLS SNI reject + QUIC/DoH block, placed above FastTrack. Verified rule hit counters on the router.

Wireless The controller that couldn't be turned off

Problem

The migration plan was to take over the old UniFi controller's IP so access points would reconnect automatically.

Root cause

Investigation showed the new VM actually ran on the old PC, which also served file shares — shutting it down would have taken everything offline.

Fix & result

Kept the host, redirected APs with an inform-host override instead. All 16 APs moved over with no site visit.

Data quality 39 birthdays silently swapped by Excel

Problem

While importing HR data into Microsoft Lists, some dates looked plausible but felt off.

Root cause

A locale mismatch made Excel read dd/mm as mm/dd. Proof: none of the 39 converted dates had a day above 12 — statistically impossible.

Fix & result

Imported the column as text exactly as displayed, left the source file untouched, and reported the affected rows to HR for correction.

Infrastructure UPS monitoring on a hypervisor without USB passthrough

Problem

UPS monitoring ran on a laptop that wasn't on 24/7, and the target Hyper-V VM couldn't see the UPS's USB port.

Root cause

Hyper-V doesn't pass USB devices through to guests.

Fix & result

Split the stack: NUT server on the physical host (firewalled to the monitoring VM only), dashboard and Telegram alerts as a systemd service on Linux.

Monitoring Alert fatigue in the NOC

Problem

One Telegram group received every alert — server, network and noisy Windows services — so real incidents got buried.

Root cause

A single alert action with no severity or scope filtering.

Fix & result

Separate Server and Network channels, severity / tag-based conditions, and exclusions for known-noisy services. Shared Grafana dashboards with a read-only viewer role.
